# LMS & LIS Research Summary

> Research date: March 2026
> Topics: Learning Management Systems (LMS) + Library Information Systems (LIS)

---

## 🎓 Learning Management Systems (LMS)

### Market Leaders

| Type | Top Platforms |
|------|---------------|
| **Enterprise** | Docebo, Cornerstone, SAP Litmos, Absorb, 360Learning |
| **Open Source** | Moodle (#1 globally), Open edX, Canvas, Chamilo |
| **Specialized** | Relias (healthcare), Trainual (SMB), Google Classroom (K-12) |

### Core Features (2026 Standard)

- Course authoring + SCORM/xAPI compliance
- Role-based access + SSO (Single Sign-On)
- Personalized learning paths
- Mobile + offline mode
- Analytics dashboards
- Compliance tracking + audit trails
- AI-powered recommendations (now baseline, not differentiator)

### Key Differentiators

| Differentiator | Leaders |
|----------------|---------|
| **AI-Native** | Docebo, CYPHER Learning, Intellum |
| **UX-First** | Absorb, TalentLMS |
| **Integration Depth** | Cornerstone (HRIS/talent), SAP Litmos (enterprise) |
| **Mobile-First** | Beedeez (offline field workforce) |
| **Collaborative** | 360Learning (peer co-creation) |

### 2026 Emerging Trends

- **AI as table stakes** — operational, not experimental
- **LXP Convergence** — ~70% of enterprise contracts include Learning Experience Platform components
- **Skills-based learning** — shift from course completion to competency
- **Microlearning** — bite-sized modules, >90% completion rates
- **AR/VR Immersive Learning** — healthcare, manufacturing, aviation
- **Blockchain Credentials** — verifiable digital badges
- **Hybrid delivery** — seamless online/in-person is now the norm

### Common Use Cases

| Use Case | Target Audience | Key Platforms |
|----------|----------------|---------------|
| Employee Onboarding | New hires | Absorb, SAP Litmos, TalentLMS |
| Compliance Training | Healthcare, finance, government | SAP Litmos, Cornerstone, Docebo |
| Customer Education | External users | Docebo, Thinkific, Teachable |
| Higher Education | Universities | Canvas, Moodle, Blackboard, Open edX |
| K-12 Education | Schools | Canvas, Schoology, Google Classroom |
| Healthcare Training | Clinical skills | HealthStream, Relias |
| Field Workforce | Retail, manufacturing | Beedeez (mobile-first, offline) |

## 📖 Library Information Systems (LIS)

### Market Leaders

| Type | Top Platforms |
|------|---------------|
| **Commercial** | Alma (Ex Libris/ProQuest), Symphony (SirsiDynix), FOLIO (EBSCO), Axiell, WorldShare WMS (OCLC) |
| **Open Source** | Koha, Evergreen, FOLIO |

### Core Features

- **OPAC** (Online Public Access Catalog) — patron-facing search
- **Circulation** — check-in/out, holds, renewals, loan rules
- **Cataloging** — MARC records, metadata (Dublin Core, RDA, BIBFRAME)
- **Patron Management** — borrower records, privileges, authentication
- **ERM** (Electronic Resource Management) — license tracking, COUNTER stats
- **Acquisitions** — vendor management, purchase orders, budgets
- **API Integrations** — LDAP, SAML, SIP2, REST APIs

### Architecture Comparison

| Platform | Architecture | Deployment | Target Market |
|----------|--------------|------------|---------------|
| Alma | Cloud-native SaaS | Fully managed | Large academic |
| FOLIO | Microservices (modular apps) | Self-host or EBSCO-hosted | Mid-large academic |
| Koha | Monolithic PHP | Self-host or hosted | Small-mid all types |
| Evergreen | Monolithic Perl | Self-host or hosted | Large consortia |

### Key Differentiators

- **Cloud-native**: Alma, FOLIO
- **Consortia-scale**: Evergreen (powers Georgia PINES — largest US public library consortium)
- **Community-driven**: Koha (global SMB adoption, free/open source)
- **API Ecosystem**: Alma (Ex Libris Developer Network), FOLIO (OKAPI gateway)

### Common Use Cases by Library Type

| Library Type | Typical Platforms | Key Needs |
|--------------|-------------------|-----------|
| **Academic** | Alma, FOLIO, WorldShare WMS | E-resource management, course reserves (LMS integration), ILL, research analytics |
| **Public** | Koha, Evergreen, Symphony, Axiell | Multi-branch, consortia support, community programming, public access |
| **School** | Koha, Accessit, Alexandria, Follett Destiny | SIS integration, curriculum alignment, simple OPAC |

### Integration Capabilities

- **Discovery Layers**: EDS, Summon, Primo, VuFind
- **Link Resolvers**: SFX, 360 Link, Alma
- **Authentication**: CAS, Shibboleth, LDAP, OAuth
- **Document Delivery**: REX, Clio, ILL systems

## 🎯 Recommendations

| Goal | Approach |
|------|----------|
| Build **LMS from scratch** | Study Moodle's architecture patterns |
| Target **enterprise LMS** | AI + HRIS deep integration, compliance focus |
| Target **SMB LMS** | Simplified UX, mobile-first, self-service |
| Build **library system (SMB)** | Koha (free, community-supported, web-based) |
| Build **modern academic LIS** | FOLIO (open, microservices, cloud-native) |
| **Enterprise LIS with legacy** | Symphony (customizable, proven at scale) |
